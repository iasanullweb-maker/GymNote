- [ ] 설치 후 앱 아이콘을 직접 눌러 첫 화면이 열리는지 확인한다. 홈 화면에 머무르거나 즉시 종료되면 기기/OS/실행 시각과 충돌 로그를 확보한다. 이전 0.1.88 클라우드 iPadOS 17.5 실행 미확인 현상의 원인은 아직 확정되지 않았으며 이번 배포가 해결했다고 판단하지 않는다.
- [ ] 업데이트 전후 같은 계정에서 운동 일지·최고 기록·계획·일상·진행 중 운동이 유지되는지 확인한다.
- [ ] 관리자 A와 일반 사용자 B를 준비한다. 친구 탈퇴·계정 삭제 검사는 개인 기록을 복구할 필요가 없는 테스트 계정으로 한다.
- [ ] 각 항목의 기기/OS/앱 버전, 성공/실패, 재현 순서, 스크린샷을 기록한다. 앱 코드 문제와 서버 미적용·네트워크·권한 상태를 구분한다.

## 실행 탭: 시작·세트·운동 순서

- [ ] 휴식일에는 운동 시작이 비활성이고, 운동 계획이 있는 날에는 정상 시작된다. 여러 번 눌러도 활성 운동이 중복 생성되지 않는다.
- [ ] 운동 중 배너에 경과 시간, 완료/전체 세트 수와 진행도가 실제 세트 체크와 함께 갱신된다.
- [ ] 실제 횟수의 −/+·직접 입력·세트 완료가 정상 동작하며, 다음 세트는 계획 횟수로 초기화된다. 완료한 세트의 실제/계획 횟수도 맞다.
- [ ] 일부 세트만 끝낸 운동은 기존 위치에 남고, 해당 운동의 마지막 세트가 끝나면 완료 묶음으로 자동 이동한다. 다른 미완료 운동의 순서는 유지된다.
- [ ] 완료 운동에서 되돌리기를 누르면 미완료 묶음의 저장 순서로 돌아온다. 세트 수·실제 횟수·무게가 함께 되돌려진다.
- [ ] 편집 모드를 켜지 않은 상태에서 운동 이름/행을 길게 눌러 끌 수 있다. 행 안 세트 완료·횟수 버튼을 누르는 동작과 충돌하지 않는다.
- [ ] 운동을 위·아래·맨 위·맨 끝으로 이동할 수 있다. 여러 번 바꿔도 운동이 사라지거나 중복되지 않는다.
- [ ] 끌다가 취소하거나 원위치에 놓으면 순서와 진행 기록이 바뀌지 않는다. 앱 밖 텍스트를 놓아도 운동 순서가 바뀌지 않는다.
- [ ] 미완료 운동을 완료 묶음으로 끌면 미완료 묶음 끝에 남고, 완료 운동을 위로 끌면 완료 묶음 안에 남는다. 놓은 뒤 움직임이 이해하기 쉽다.
- [ ] 순서를 바꾼 뒤 세트 수·운동 ID·실제 횟수·무게·휴식 타이머가 유지된다. 이미 저장된 일지가 변경되지 않는다.
- [ ] 순서 변경 후 다른 탭 왕복·백그라운드 복귀·앱 완전 종료/재실행에도 순서와 완료 수가 유지된다. 실행할 때마다 완료 수가 늘어나지 않는다.
- [ ] 저장된 일정과 같은 운동 구성이라면 새 운동 시작에도 변경 순서가 유지된다. 계획의 세트·횟수 자체가 바뀌지 않는다.
- [ ] 자정 전에 시작한 운동을 자정 후 이어서 체크/종료한다. 시작한 운동의 계획·날짜·진행 기록이 유지된다.

## 실행 탭: 휴식·종료·저장

- [ ] 세트 완료 후 설정한 기본 휴식이 시작되고 분·초가 맞다. 휴식 시간이 지난 뒤 운동 중 상태로 돌아온다.
- [ ] 휴식 건너뛰기, 기본 휴식 −/+ 간격, 수동 휴식 시작이 동작한다. 운동 없이 휴식만 시작하면 세트 수를 표시하지 않는다.
- [ ] 일부 세트 완료 후 운동 마치기: **운동 중 → 운동 완료 → 운동 일지에 저장됨 → 표시 사라짐** 순서가 보인다. 세트 수·소요 시간과 일지가 맞다.
- [ ] 계획의 마지막 세트 완료로 자동 저장될 때도 종료 표시가 나오고 휴식 타이머는 새로 시작되지 않는다.
- [ ] 0세트 상태에서 시작 취소하면 활성 운동만 정리되고 일지와 저장 완료 표시는 생기지 않는다.
- [ ] 저장 완료 직후 새 운동을 시작하면 이전 종료 표시가 사라지고 새 진행 상태가 보인다.
- [ ] 종료 표시 도중 탭을 이동해도 상태가 이어지고, 계정을 바꾸면 이전 계정의 종료 표시가 사라진다.
- [ ] 수동 종료·자동 종료 뒤 일지는 한 개만 생긴다. 앱 재실행 후에도 중복되지 않고 실제 횟수·무게가 보존된다.
- [ ] 기기에서 저장 오류가 발생한다면 저장 완료를 표시하지 않고 활성 운동·기존 휴식을 유지한다. 실패한 세트로 휴식을 시작하거나 재시작하지 않는다. 이 항목은 CI에서도 검증했다.

## 전체 화면·입력·접근성

아래 화면 조합에서 운동 중·휴식 중·종료 표시를 각각 확인한다. 캡처에는 배너와 탭 막대, 목록 마지막 버튼이 함께 나오게 한다.

- [ ] iPad 세로·가로·분할 화면(좁은 폭 포함).
- [ ] 가능하면 iPhone SE 작은 화면 세로·가로와 일반 iPhone.
- [ ] 기본 글자 크기와 접근성 큰 글자(최대 크기 포함). 배너 글자에는 상한이 있으나 본문은 커진다.
- [ ] 실행·계획·기록·친구·설정 탭에서 배너가 탭 막대를 가리지 않고, 마지막 버튼까지 스크롤해 누를 수 있다.
- [ ] 운동/일상 전환 후에도 활성 운동/휴식이 유지되고 진행 중 운동으로 돌아갈 수 있다.
- [ ] 긴 운동명·많은 운동·완료 세트 상세가 있는 목록에서 가로 넘침·잘림·스크롤 튐·버튼 겹침이 없다.
- [ ] 키보드가 열린 친구 입력/직접 횟수 입력/기록 입력에서 배너·키보드·저장/취소 버튼이 입력을 막지 않는다.
- [ ] VoiceOver가 운동명·실제 횟수·세트 진행도를 이해할 수 있게 읽고 위/아래/맨 위/맨 아래 이동 동작을 제공한다.
- [ ] ‘동작 줄이기’에서 순서 변경·종료 표시가 이해하기 쉽고 과도한 움직임이 없다. 종료 시 저장됨 안내도 들린다.

## 기록 탭·입력 경로

- [ ] 탭 첫 진입 기본 화면과 표시 순서가 **운동 일지 → 친구 → 최고 기록**이다.
- [ ] 최고 기록에 +가 없고 조회 화면에 추가/수정/삭제 진입점이 없다. 그래프·기록 내역은 정상 조회된다.
- [ ] 기록 → 친구 → 순위 보기에는 친구 추가 버튼이 없다. 친구 추가는 친구 탭의 친구 목록 첫 줄에서 한다.
- [ ] 실행 탭 ‘종목 기록 남기기’에서 활성 공통 종목을 선택해 입력/저장할 수 있다.
- [ ] 기존 최고 기록보다 낮은 값도 저장되고 ‘기록을 저장했어요’가 나온다. 더 좋은 값은 신기록 안내가 나오고 시트 종료 후 알림이 보인다.
- [ ] 횟수와 라운드는 정수만, 무게·시간 등 측정 단위는 해당 종목 규칙에 맞는 소수 입력이 가능하다. 라운드+추가 횟수가 순위에 올바르게 반영된다.
- [ ] 지난 운동 입력/세트별 실제 횟수·무게 수정이 일지와 자동 최고 기록에 반영된다. 저장/취소에 따라 결과가 맞고 다른 일지가 변경되지 않는다.
- [ ] 최고 기록은 직접 기록과 운동 일지의 유효한 기록을 비교한다. 사용 중단 종목·이전 개인 기록은 보존되어 조회된다.
- [ ] 기록/설정 탭을 빠르게 오가거나 갱신을 취소해도 ‘공통 종목을 갱신하지 못했어요’가 불필요하게 나타나지 않는다. 실제 연결 실패에서는 저장된 목록을 사용할 수 있다.

## 친구: 가입·요청·공개·탈퇴

- [ ] 가입 화면 제목·설명·닉네임·공개 설정·가입 버튼이 작은/큰 화면에서 읽기 쉽다. 공백·빈 닉네임·20자 초과 입력이 올바르게 처리된다.
- [ ] 가입 후 닉네임과 친구 코드가 보이고 친구 추가 버튼이 친구 목록 첫 줄에 있다. 상단 중복 버튼이 없다.
- [ ] A가 B에게 코드로 요청 → B 수락 후 양쪽 친구 목록과 순위가 맞는다. 보낸 요청 취소·거절·친구 끊기도 양쪽에 반영된다.
- [ ] 상호 요청·이미 친구인 코드·잘못된 코드·내 코드 입력이 중복 관계나 잘못된 안내를 만들지 않는다.
- [ ] A가 그룹 생성 → B 초대 → B 참여 후 순위가 보인다. 참여 전에는 그룹 순위를 볼 수 없고 비참여 계정에는 기록이 노출되지 않는다.
- [ ] 그룹장이 나가거나 친구 기능을 탈퇴하면 남은 가입자에게 그룹장이 이전된다. 마지막 참가자가 나가면 빈 그룹이 정리된다.
- [ ] 공개 켜기 후 실행/지난 운동 기록 변경이 다른 계정 순위에 반영된다. 동점·높을수록/낮을수록 좋은 종목·라운드 점수가 맞다.
- [ ] 공개 끄기 후 다른 계정에서 내 공개 기록이 사라지고 개인 기록은 남는다. 다시 켜면 유효한 현재 최고 기록만 올라간다.
- [ ] 친구 기능 탈퇴의 취소는 기존 상태를 유지한다. 확인 시 닉네임·코드·친구 관계·그룹 참여·공개 기록이 제거된다.
- [ ] 탈퇴 후 앱 로그인·개인 운동/일상/최고 기록·클라우드 백업은 유지된다. 다른 계정에서도 이전 관계/공개 기록이 사라진다.
- [ ] 탈퇴 직전 갱신/공개가 진행 중이거나 앱을 다시 열어도 이전 프로필이 살아나지 않는다.
- [ ] 재가입하면 새 친구 코드가 생기고 이전 친구·그룹 관계는 복원되지 않는다.
- [ ] 네트워크 단절/서버 미적용으로 탈퇴가 실패하면 성공으로 표시하지 않고 기존 프로필·관계를 유지한다.
- [ ] 계정 전환·로그아웃 뒤 이전 계정의 친구 프로필·가입 입력·순위·임시 창이 남지 않는다.

## 관리자 공통 종목: 운영 두 계정 확인

- [ ] 관리자 A가 새로운 공통 최고 기록 종목을 활성 상태로 추가한다. 일반 사용자 B와 게스트가 새로고침/기록 종류 전환 후 같은 이름·단위·순서를 본다.
- [ ] B가 앱을 켜 둔 상태에서도 활성 중 60초 갱신으로 새 종목을 받는다. 백그라운드 복귀와 재실행 후에도 최신 목록을 본다.
- [ ] 관리자 화면을 1분 이상 켜 두면 주기 갱신 때 화면이 깜빡이거나 관리자 표시가 사라지지 않고, 다른 계정 작업도 가능하다.
- [ ] 관리자만 추가/수정 화면을 사용하며 B·게스트에는 관리자 기능이 없다. 서버 권한이 실제로 해제되면 관리자 표시가 갱신된다.
- [ ] 이름·설명·순서·활성 상태 변경이 B에 반영된다. 비활성 종목은 신규 입력에서 사라지지만 기존 기록은 보존된다.
- [ ] 오프라인에서도 마지막 정상 공통 목록으로 조회/기록할 수 있고 재연결 후 갱신된다.
- [ ] 새 종목이 ‘공통 최고 기록 종목’인지 ‘개인 루틴 운동’인지 구분한다. 개인 루틴 추가가 모든 이용자에게 공유되는 기능은 이번 변경 범위가 아니다.

## 기존 기능 회귀: 배포 후 함께 확인

- [ ] 이메일·Google·사용 가능한 Apple 로그인 후 앱으로 복귀하고 취소/실패 시 기존 기기 기록이 유지된다. 로그인 계정과 선택 데이터가 일치한다.
- [ ] 로그아웃·다른 계정 로그인·게스트 기록 가져오기에서 계정별 기록이 섞이지 않고, 가져오기 재시도에 중복이 생기지 않는다.

# 실제 iPad 기반 사용성 검증

## 목표와 현재 상태

사용자 승인 순서는 **1. 실제 iPad 미러링 관찰 → 2. 클라우드 실제 iPad 가상 사용자 실험**이다. 웹 프로토타입은 참고 자료이며 실제 앱의 사용성 근거로 사용하지 않는다. 1단계 수신·자동 관찰은 확인했다. 설정 → 계획 → 설정 복귀와 휴식 90초/간격 15초 유지 관찰 완료. 2단계는 체험 계정 가입 및 클라우드 실제 설치 확인 대기다.

## 1단계: Windows 수신 환경

1. PC에서 [공식 다운로드](https://www.airserver.com/Download)를 열고 Windows 10/11용 AirServer 체험판을 설치·실행한다. 체험판 종료 후 결제 여부는 사용자가 결정한다.
2. PC와 iPad를 같은 Wi-Fi에 연결한다. iPad에 별도 수신 앱을 설치할 필요는 없다.
3. iPad 오른쪽 위에서 내려 제어 센터 → 화면 미러링 → PC의 AirServer 수신기를 선택한다. 코드가 나오면 사용자가 입력한다.
4. GymNote를 열고 가로/세로 전환과 탭 이동이 PC 수신 화면에 반영되는지 확인한다.
5. CLI와 AirServer를 같은 활성 Windows 가상 데스크톱에 두고, 수신 창을 전면 표시한다. 다른 데스크톱에서는 창 조회가 누락될 수 있다. 에이전트는 Windows Computer Use에서 반환된 AirServer 창을 선택해 화면을 관찰한다. 창이 없거나 화면 캡처가 실패하면 관찰 완료로 기록하지 않는다.

[공식 연결 절차](https://support.airserver.com/support/solutions/articles/43000535997-how-to-screen-mirror-your-iphone-or-ipad-to-airserver). 수신기가 안 보이면 같은 네트워크인지, AirServer가 실행 중인지 확인하고 학교/게스트 네트워크의 기기 간 통신 제한을 점검한다. 방화벽·보안 승인 창은 사용자가 처리한다. 검증 종료 후 제어 센터에서 미러링 중단.

## 관찰과 기록

사용자가 실제 iPad를 터치하고 에이전트가 전후 화면을 확인한다. 미러링은 원격 터치 기능이나 상시 영상 분석 기능이 아니다. 화면만으로 터치 횟수·지연·저장 성공을 추정하지 않는다. 사용자 진술은 관찰 결과와 구분한다.

[세션 양식](templates/real-device-session.md)을 복사해 로컬 simulation/runs/ 아래에 보관한다. 개인 계정 화면·친구 코드·알림을 Git에 추가하지 않는다. 필요한 경우 재현 절차와 익명화한 문제만 결과 문서에 옮긴다. 기존 실제 기록을 변경하는 시나리오는 테스트 데이터로 수행한다.

첫 검증은 탐색(실행/계획/기록/친구/설정), 계획 편집의 저장·취소 및 이동 잠금 해제, 운동 시작→세트 완료→휴식→일지 확인이다. 각 과제의 기대 행동을 먼저 설명하고 조작 전후 화면·막힌 지점·사용자 반응을 기록한다. 관찰하지 않은 항목은 pending으로 유지한다.

1단계 완료 기준: 실제 수신 화면을 에이전트가 확인하고 최소 한 과제의 시작/중간/끝 화면과 사용자 수행 결과를 기록한다. 설치 성공만으로 사용성 검증 완료를 선언하지 않는다.

## 2단계: 실제 기기 클라우드

1단계 근거 확보 후 BrowserStack App Live 등에서 GymNote IPA 설치·실행 가능 여부와 원하는 iPad/OS 제공 여부, 비용을 확인한다. [App Live](https://www.browserstack.com/docs/app-live/overview/introduction)는 브라우저에서 실제 기기 앱을 조작하는 서비스다. IPA 업로드·계정/요금제 선택은 별도 진행한다.

자동 반복 실험에는 조작 어댑터, 가상 사용자별 초기 데이터, 실행 간 초기화, 화면/행동 증거 수집, 실패 중단·재개, 평가 연결이 추가로 필요하다. 재서명으로 권한이 달라질 수 있으므로 로그인·알림·저장을 각각 검증한다. 웹 결과와 실기기 결과는 별도로 보존한다.

2단계의 현재 IPA와 시작 절차: [클라우드 실험 준비](../../simulation/cloud/README.md).

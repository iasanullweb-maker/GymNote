# 누를 수 없는 버튼의 회색 비활성 표시 (2026-10-21)

## 요청

- 휴식일에 실행 탭의 ‘운동 시작’을 눌러도 아무 일이 없어 버그처럼 보인다. 누를 수 없는 상태임을 알 수 있게 회색으로 바꾼다.
- 눌러도 기능이 없는데 주황색(누를 수 있어 보이는) 버튼이 있으면 같은 방식으로 고친다.

## 변경

| 위치 | 문제 | 수정 |
|---|---|---|
| `App/AppModel.swift` `startWorkout` | 화면은 `currentDate`(앱이 마지막으로 갱신한 날짜)의 계획으로 버튼 색을 정하지만, 실제 시작은 `Date()`의 계획으로 판정했다. 날짜가 바뀌어 화면 갱신 전 오늘이 휴식일이면 주황 버튼을 눌러도 조용히 무시됐다. | 시작 전에 날짜를 갱신하고, 진행 중 운동이 있거나 휴식일이면 시작하지 않는다(화면이 휴식일·회색 버튼으로 바뀜). 시작은 갱신한 `currentDate`로 한다. |
| `App/TodayView.swift` 운동 시작 바 | 휴식일 비활성 이유가 화면에 없었다. | 휴식일 회색 버튼 아래 “휴식일에는 운동을 시작할 수 없어요. 계획 탭에서 이 날짜에 운동을 추가하면 시작할 수 있어요.” 안내와 VoiceOver 힌트를 추가했다. |
| `App/ManualWorkoutView.swift` ‘선택한 날짜의 루틴’ | 휴식일만 비활성이었고, 등록 종목이 없거나 세트 0인 루틴은 주황색인데 눌러도 아무것도 추가되지 않았다. | 실제로 가져올 운동이 없으면 비활성(회색). |
| `App/ManualWorkoutView.swift` ‘이전 운동 일지’ 메뉴·항목 | 등록 종목의 완료 세트가 없는 일지 항목은 눌러도 아무것도 추가되지 않았다. | 가져올 운동이 없는 항목은 비활성, 모든 일지가 그렇다면 메뉴 자체를 비활성. |
| `Tests/WorkoutFlowTests.swift` | — | 휴식일 시작 무시·휴식 계획 유지 회귀 테스트 추가. |

## 점검했지만 바꾸지 않은 버튼

앱 전체 `Button`의 액션 안 `guard … return`과 `.disabled` 조건을 대조했다. 세트 완료·−/+·되돌리기·계획 저장·기본 루틴 추가·로그인/계정/친구·운동 종목 관리 버튼은 이미 같은 조건으로 비활성화되어 있었다. 휴식 타이머·위젯 세트 체크는 휴식일에도 실제 동작(타이머 시작 등)이 있어 그대로 둔다.

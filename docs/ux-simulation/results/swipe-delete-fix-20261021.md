# 짧은 밀기 삭제 화면 깨짐 수정 (2026-10-21, Claude)

## 증상 (사용자 제보, iPad 실기기 0.1.119 다크 모드)

계획 탭 → 캘린더 날짜 길게 누르기 → 날짜 계획 시트에서 운동 행을 왼쪽으로 밀면 운동 이름이 사라지고(“5회”만 반쯤 보임), 빨간 삭제 버튼이 행보다 크게 튀어나오며 어두운 사각형이 버튼 왼쪽을 가려 “삭제” 글자가 잘렸다.

## 원인

`App/ShortSwipeAction.swift`(2026-10-09, 넓은 iPad에서도 짧게 밀어 삭제하려고 만든 직접 구현)가 목록 기본 행 여백 안쪽에서만 그려졌다.
- 행 내용을 왼쪽으로 80pt 옮겨 짧은 글자가 여백 경계에서 통째로 잘렸다.
- 버튼은 위아래 12pt 패딩으로 내용보다 키가 커서 행 배경(내용 높이만큼만 칠함) 위아래로 삐져나왔고, 손을 떼기 전 위치에서는 행 배경이 버튼 일부를 덮었다.

## 수정 (Impeccable critique → DESIGN.md 기준)

- 행 여백(위아래 11pt·좌우 20pt)을 modifier가 직접 그리고 `listRowInsets`를 0으로 바꿔 버튼이 행 높이 전체를 쓴다.
- 행 글자는 제자리에 두어 어떤 운동을 지우는지 계속 보인다. 오른쪽에서 둥근 빨간 버튼(12pt continuous, 위아래 6pt·오른쪽 8pt 여백)이 밀린 거리만큼 자라며 덮고, 버튼 왼쪽 16pt는 행 배경색으로 부드럽게 사라진다. 버튼이 좁으면 휴지통 아이콘만, 더 좁으면 빈 빨간 모양만 보여 글자가 잘리지 않는다.
- 이동 거리(36pt 열기·120pt 바로 실행·오른쪽 36pt/탭으로 닫기), 편집 모드 빼기 버튼, 접근성 삭제 동작, 확인 창은 그대로다. 애니메이션은 `.snappy(0.2)`, 동작 줄이기에서는 없음.
- 같은 modifier를 쓰는 운동 일지·운동 목록·일상 완료 취소에도 함께 적용된다.
- DESIGN.md에 “Short Swipe Delete” 예외 컴포넌트를 기록했다.

## 남은 충실도 차이

픽셀 단위 복제는 아니다. SwiftUI 글꼴·네이티브 시트/키보드·스크롤/제스처와 앱의 전체 상태를 동일하게 구현하지 않는다. 사진의 운동은 완료 상태지만 실험 시작은 미완료 합성 푸쉬업 3세트다. 기록 화면도 편집 취소 실험을 위해 수동 기록 18회가 존재한다.

일상, 그룹 생성, 새 최고기록 추가, 알림, 서버 동기화, 세트 되돌리기는 이번 시나리오 범위 밖으로 안내하거나 비활성화했다. 사진에 없는 활성 운동·편집/추가 창은 코드와 합성 상태에 따른 근사이며 실제 화면 추가 대조가 필요하다. 특히 전체 기록 보기에서 편집으로 바로 진입하는 웹 단축과 세트별 횟수를 쉼표로 입력하는 폼은 실제 앱의 중간 화면을 모두 재현한 것이 아니다. 이 구간의 편의성 결과를 실제 앱 결과로 일반화하지 않는다.

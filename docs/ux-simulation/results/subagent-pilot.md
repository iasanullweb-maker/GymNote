# 실기기 subagent 파일럿 준비

2026-10-10 사용자 요청에 따라 초보·주의 분산 사용자와 실행 후 기획자 설계를 세 subagent가 읽기 전용으로 검토했다. 이 활동은 앱 사용 실험이 아니다. 실제 사용자 역할은 소스·이전 대화를 상속하지 않는 새 subagent에서 시작한다.

현재 가로 방향의 270° 클릭·드래그는 사용자가 보이는 그대로 입력됨을 확인했다. 연결 안정성은 별도 미확정이다. 첫 범위는 기록 변경 없는 실행·계획·기록·설정 탐색이며 친구·계정·외부 앱·설정 변경·운동 기록 변경은 제외한다. 초기 화면에 실제 개인 기록이 보이면 사용자 역할에 전달하지 않는다.

[파일럿 안내](../pilot/README.md)에 역할 프롬프트, 사용자별 두 목표, 단일 기기 직렬 중계, 실제 증거 기록과 중단·기획 평가 절차를 준비했다. 준비 스크립트는 로컬 run 폴더만 생성하고 기기·모델·외부 서버에 접속하지 않는다. 기존 demo-v1/session 규격이나 dry-run 실행기를 live 실행으로 바꾸지 않았다. 실제 설치 앱 SHA는 미확인으로 null이며 뷰어 SHA와 분리한다.

검증 통과: 새 준비 실행으로 목표별 프롬프트 4개와 미평가 메타데이터를 확인하고 같은 run ID 덮어쓰기 및 경로 이탈 인수를 거부함을 확인했다. 사용자 프롬프트에는 정답 경로·평가 기준·다른 사용자 결과를 넣지 않았다. 과제는 서로 다르므로 역할 간 수치 비교나 실제 사용자 성공률로 해석하지 않는다.

남은 단계: 개인정보 없는 시작 화면을 확인해 독립 사용자별 실제 탐색을 수행하고, 단계별 전후 증거로 기획 평가를 실시한다. 모델 사용량은 확인 가능한 값만 기록한다. 저장·편집 실험은 격리 초기 데이터와 전후 상태 검증 준비 후 확장한다. 전체 iOS 빌드·원격 push·배포는 이 준비에서 수행하지 않는다.

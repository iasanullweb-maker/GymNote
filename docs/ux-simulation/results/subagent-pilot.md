# 실기기 subagent 파일럿 준비

최신 후속 실행: 새 사용자 역할 4개와 기획자 1개로 현재 설치 화면을 다시 탐색했다. 기록 목록은 확인했으나 원격 탭·영상 갱신 문제로 세트별 상세는 pending이다. [후속 파일럿 결과](subagent-followup-pilot-20261010.md)를 따른다. UI 수정 적용 후 검증은 아니다. 앞선 실행은 [직접 화면 파일럿 결과](subagent-live-pilot-20261010.md)에 보존한다. 아래는 준비와 첫 전사 중계 시점의 이력이다.

2026-10-10 사용자 요청에 따라 초보·주의 분산 사용자와 실행 후 기획자 설계를 세 subagent가 읽기 전용으로 검토했다. 이 활동은 앱 사용 실험이 아니다. 실제 사용자 역할은 소스·이전 대화를 상속하지 않는 새 subagent에서 시작한다.

현재 가로 방향의 270° 클릭·드래그는 사용자가 보이는 그대로 입력됨을 확인했다. 연결 안정성은 별도 미확정이다. 첫 범위는 기록 변경 없는 실행·계획·기록·설정 탐색이며 친구·계정·외부 앱·설정 변경·운동 기록 변경은 제외한다. 초기 화면에 실제 개인 기록이 보이면 사용자 역할에 전달하지 않는다.

[파일럿 안내](../pilot/README.md)에 역할 프롬프트, 사용자별 두 목표, 단일 기기 직렬 중계, 실제 증거 기록과 중단·기획 평가 절차를 준비했다. 준비 스크립트는 로컬 run 폴더만 생성하고 기기·모델·외부 서버에 접속하지 않는다. 기존 demo-v1/session 규격이나 dry-run 실행기를 live 실행으로 바꾸지 않았다. 실제 설치 앱 SHA는 미확인으로 null이며 뷰어 SHA와 분리한다.

검증 통과: 새 준비 실행으로 목표별 프롬프트 4개와 미평가 메타데이터를 확인하고 같은 run ID 덮어쓰기 및 경로 이탈 인수를 거부함을 확인했다. 사용자 프롬프트에는 정답 경로·평가 기준·다른 사용자 결과를 넣지 않았다. 과제는 서로 다르므로 역할 간 수치 비교나 실제 사용자 성공률로 해석하지 않는다.

남은 단계: 개인정보 없는 시작 화면을 확인해 독립 사용자별 실제 탐색을 수행하고, 단계별 전후 증거로 기획 평가를 실시한다. 모델 사용량은 확인 가능한 값만 기록한다. 저장·편집 실험은 격리 초기 데이터와 전후 상태 검증 준비 후 확장한다. 전체 iOS 빌드·원격 push·배포는 이 준비에서 수행하지 않는다.

## 첫 수동 중계 파일럿 수행

2026-10-10 사용자 진행 요청 후 실제 iPad 화면을 부모가 관찰하고, 독립 초보 역할 두 과제와 주의 분산 역할 두 과제를 직렬 중계했다. 사용자는 현재 상태를 일부러 조작해 두었다고 설명했고 실행 제목에는 테스트 문구가 보였다. 모든 기록이 합성 데이터라고 확인한 것은 아니다. 모델에는 이미지 대신 부모가 옮긴 화면 구조를 제공하고 실제 운동 내용·수치는 제외했다. 기획자는 종료 후 기록만 검토했다. 사용자 역할 10회, 기획 검토 1회 응답을 받았으며 API 요청·토큰 수와 모델 정확한 식별자는 미확인으로 남겼다.

| 과제 | 실제 관찰 | 판정 제한 |
|---|---|---|
| 초보: 계획/수행 구분 | 계획→기록 탭을 제안했고 실제 전환 화면을 확인했다. 계획 달력과 운동 일지의 의미를 구분했다. | 화면 문구·탐색 수준의 관찰이며 저장 검증 아님 |
| 독립 초보: 보관 단서 | 실행의 저장 표시를 본 뒤 기록 탭을 찾아 운동 일지 표시를 확인했다. | 방금 운동과의 일치·재실행 유지·동기화 미평가 |
| 주의 분산: 오늘 정보 | 계획 탭에서 오늘과 다른 선택 날짜를 발견했다. | 운동 내용 미제공·날짜 선택 금지로 not-evaluated; 제품 실패 아님 |
| 주의 분산: 문맥 복귀 | 실행 화면을 거쳐 계획으로 복귀해 이전 선택 날짜의 강조 표시를 확인했다. | 날짜 문맥만 관찰; 운동 내용·인간 주의력 미평가 |

연결 사전 점검에서 `frames: 0`, codec HTTP 500과 서버의 `userspace dial plane is closed`를 확인했다. 본인 서버를 새 연결로 재시작한 뒤 영상 수신을 확인했다. 이후에도 수초 단위 중단·복구가 반복돼 장시간 안정성을 인정하지 않는다. 첫 데스크톱 클릭은 즉시 결과가 불명확했고 전면·최대화·배율 정리와 별도 브라우저 관찰 뒤 최종 계획 도착을 확인했다. 어떤 초기 클릭이 반영됐는지 확정하지 않는다. 일부 마지막 탭 이동은 관찰한 canvas 영역과 확인된 270° 변환으로 같은 루프백 `/touch` 경로에 중계하고 결과 화면을 확인했다. 개인정보 설정·운동 기록·날짜 선택은 변경하지 않았다.

자동 승인 검토가 기록 화면의 이미지 파일 저장을 거부했다. 실제 운동·건강 정보 포함 가능성이 미확인이라는 이유다. 우회 저장하지 않았으며 이미지가 없는 화면 구조 전사와 행동 로그만 로컬 `simulation/runs/usb-pilot-first-attempt-20261010-1414/`에 남겼다. 원본 이미지를 모델에 전달하거나 Git에 넣지 않았다. 여러 뷰어와 전송 지연은 환경 제한으로 기록하고 사용자 실수에 합산하지 않았다.

기획 검토 결론은 **입증된 제품 문제 없음, 전체 결과 inconclusive**다. 저장 표시에서 해당 기록으로 이동하는 동선과 오늘/선택 날짜 구분은 후속 검증 가설이다. 기존 오늘 컨트롤은 이미 있으며 선택 날짜 유지는 의도된 동작일 수 있다. 과제가 서로 다르고 반복·직접 이미지 입력이 없어 성공률이나 실제 사용자 의견으로 표현하지 않는다. 제품 코드는 수정하지 않았다.

검증: 과제 4개·사용자 단계 10개·총 역할 응답 11회·미확인 앱 SHA null·이미지 미저장·저장 상태 성공 판정 없음 확인. 다음은 설치 빌드 확인, 전체 합성 데이터 준비, 승인 범위 내 직접 화면 전달, 날짜 탐색을 허용한 동일 과제 반복과 전송 안정화다. 전체 iOS 빌드·push·배포 미실행.

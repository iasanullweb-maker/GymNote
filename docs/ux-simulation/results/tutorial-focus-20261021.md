# 튜토리얼 집중도 개선 (2026-10-21, 미배포)

- 기준: 원본 main `476f6c6`, 작업 브랜치 `codex/tutorial-focus-20261021`. 사용자 요청: 짧은 글·실제 버튼 강조·집중을 돕는 움직임. 기존 8개 안내·건너뛰기 없음·완료 기기 저장을 유지한다.
- 모든 단계를 짧은 제목+한 문장으로 축약. 운동 시작 버튼, 일상 + 버튼, 선택 날짜 셀, 친구 추가 버튼에 실제 Anchor를 연결했다. 운동 중/휴식일에는 해당 상태에 맞는 설명을 사용한다.
- 카드가 실제 대상 아래 또는 위에 배치되고 가로 위치도 대상에 맞춰 화면 안으로 보정된다. 강조를 카드 위치에서 자르는 이전 방식을 제거했다. 대상이 없거나 화면 밖이거나 큰 글자/짧은 화면으로 카드와 함께 표시할 공간이 없으면 가짜 전체 화면 강조 없이 설명·다음 버튼을 표시한다. 자동 스크롤은 추가하지 않았다.
- 작업 공간 색(운동 주황/일상 청록)의 테두리·방향 화살표·52pt 진행 버튼. 100ms 후 240ms 페이드/8pt 이동으로 카드가 나타나고 테두리는 두 번만 반응한다. 단계 변경·닫기에서 Task 취소, 동작 줄이기에서는 정적 표시. 설정 > 사용 안내 > 튜토리얼 다시 보기로 기기 완료 설정만 초기화한다. 기존 완료 사용자를 자동 재노출하지 않는다.
- 검사: 변경 Swift 7개를 번들 Python 3.12 + 원본 `.validation-tools/swift-parser` Tree-sitter로 기준과 대조. 새 구문 오류 0(DailyViews 기존 footer 파서 한계 42행 동일), 명시 대상 Anchor 6개 대조와 동적 날짜 셀·작업 공간 대상 수동 검토, diff/공백 검사 통과.
